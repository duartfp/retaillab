# RetailLab

A minimal ecommerce application, built to practice modern development tooling (Docker, Kubernetes, CI/CD, AI integration) while leaning on a retail domain background.

## Stack

- **Backend**: Spring Boot (Java), Spring Data JPA, Spring Security
- **Frontend**: React
- **Database**: PostgreSQL
- **AI**: Anthropic API, used for sales insights and product recommendations
- **Infra**: Docker, docker-compose, Kubernetes (k3s locally, managed cluster later), GitHub Actions
